# Security Policy

## Supported versions

RegainPlus is an actively developed personal/open-source project. Security-related fixes are provided on a best-effort basis for the latest released version and the `main` branch.

## Reporting a vulnerability

If you discover a security or privacy issue:

1. **Do not open a public issue with exploit details** if the issue could put users at risk.
2. Report it privately to the maintainer (include steps to reproduce, affected version/device/Android version, and impact).
3. If private reporting is not available, open a minimal public issue without sensitive exploit details and request a private follow-up channel.

Please redact personal/sensitive data from logs, screenshots, and reports.

## Scope notes

- RegainPlus is designed to work offline and store data locally by default.
- Permissions such as Accessibility, Usage Access, overlay, notifications, and alarms are used for on-device functionality; misuse or unsafe configurations on shared devices can have privacy/safety implications.
- Only analyze/test devices and apps you own or are authorized to use.
